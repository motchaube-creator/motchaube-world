# Мир из стихов — свод 64 квадратов

Прототип: 64 левитирующие плитки, каждая — гексаграмма с темой, 6 полками-стадиями и массивом текстов.

## Как открыть

Двойной клик по `index.html` (сервер не нужен: данные подключены как обычный скрипт).

```
poetry-world/
├── index.html            свод плиток
├── styles.css            внешний вид и левитация
├── app.js                логика: метрики, фильтры, раскрытие квадрата
├── data/hexagrams.js     64 гексаграммы: кит. имя, пиньинь, рус. имя, триграммы, тема, 6 полок
├── scripts/validate.js   проверка данных: node scripts/validate.js
├── concept.md            общий концепт мира
├── squares.md            спека левитирующих квадратов
└── corpus-ecritsf.md     разбор канала @EcritsF → механики и маппинг цикла I–V
```

## Что уже работает

- 64 плитки с настоящими чертами гексаграмм (ян — сплошная, инь — прерывистая);
- левитация: высота и размах = объём и активность квадрата, свечение = плотность, цвет = верхняя триграмма;
- фильтр по 8 триграммам, поиск (имя, пиньинь, тема, подписи полок), режим «только мои», переключатель «без левитации»;
- клик по плитке — раскрытие квадрата: тема, «над чем / как», метрики и 6 полок-стадий;
- 7 квадратов помечены как «мои» — там стоят заглавия цикла I–V из канала @EcritsF (2, 20, 36, 38, 46, 52, 56).

### Публикация текста и расщепление (пункт 3)

Кнопка **«Писать»** в шапке открывает окно публикации:

1. вставляешь стих → кнопка **«Расщепить»** показывает родившихся сущностей:
   - **строки → юниты**: слоги, темперамент (короткая стопа / ровная поступь / длинный размах), роль (первопроходец / спутник / тень), стихия;
   - **слова → спутники**: слоги, стихия (вода / ветер / камень / небо), метка редкого слова, **рифменная родня** (слова с общим окончанием);
   - **концепты → силы квадратов**: образ → номер гексаграммы (например «дорога» → №56 旅 Странник);
2. сайт сам **подсказывает квадрат** по образам текста (кто сильнее по числу попаданий) — можно принять подсказку одной кнопкой или выбрать вручную;
3. выбираешь **полку (стадию)** и жмёшь «Опубликовать» → текст встаёт на полку, плитка получает метку с числом текстов, метрики и левитация пересчитываются, полка на черте подсвечивается как «живая».

Тексты сохраняются в `localStorage` (`poems-world:v1`), поэтому счётчик и метки видны после перезагрузки.

### Шевеление черты 動爻 (пункт 5)

Черты квадрата не назначаются вручную — их двигает само письмо:

- **полка с текстами становится ян** (проявлена), пустая — инь. Полка = черта: 1-я полка → нижняя черта, 6-я → верхняя;
- отсюда у квадрата две формы: **книжная 卦** (как в каноне) и **живая 卦** (что вышло после текстов);
- разница между ними — **сдвинутые черты**. В панели видно строку вида
  `книжная 卦 №56 旅 Люй` / `живая 卦 巽 … — сдвинулось черт: 2 (001101 → 011101)`;
- черты, которые сдвинулись, рисуются **киноварью** на плитке, а сам квадрат помечается `moved` (киноварная рамка) — сдвинувшиеся квадраты видно на своде сразу;
- в подсказке под сводом: `шевелятся черты в N квадратах`.

**Пути перемены** — в панели квадрата кнопками-переходами (клик открывает соседний квадрат и подводит к нему свод):

| Путь | Что делает | Канонический пример |
|---|---|---|
| 動爻 ×6 | смена одной черты (шесть ближайших соседей) | из 56 旅 — шесть соседей |
| 錯卦 | инверсия: все шесть черт наоборот | 63 既済 → **64 未済** |
| 綜卦 | переворот: обратный порядок черт | 63 既済 → **64 未済** |

Это и есть карта дорог: маршрут по своду строится не «по сетке», а по превращениям гексаграмм,
а «шевеление» даёт квадратам историю — каждый квадрат помнит, какие черты в нём подвинулись.

## Оформление: китайская живопись

Палитра взята из 水墨画 и красок 颜料, а не из «дизайна в китайском стиле»:

| Токен | Цвет | Что это |
|---|---|---|
| `--paper` `#efe7d6` | 宣纸 | рисовая бумага (фон, тон с волокном) |
| `--ink` `#241f1c` | 墨 | тушь для черт гексаграмм, текста и цифр |
| `--seal` `#a83a2c` | 朱砂 | киноварь: печать 印章, живые черты, акценты |
| `--gold` `#c2a145` | 赭黄 | золотая охра (триграмма 乾) |
| `--celadon` `#5f8f80` | 青碧 | селадон (триграмма 巽) |

Пигменты восьми триграмм (в `data/hexagrams.js`, поле `palette`): 赭黄 乾, 赭石 坤, 青莲 震,
石青 坎, 朱砂 离, 石绿 艮, 青碧 巽, 藕荷 兑. Цвет работает как **размывка по бумаге** (`::after`),
а сами черты гексаграммы рисуются **тушью** — так цвета не спорят с текстом.

Детали стиля:
- номер гексаграммы и число текстов — **оттиски печати** (белый 汉字/цифра на киновари 印章);
- иероглифы набираются каллиграфическим шрифтом `KaiTi / STKaiti / Songti SC` (с запасными serif),
  русский текст — старым антиквенным serif;
- левитация мягкая (5–14 px), а метка «мой квадрат» — тонкая линия киновари;
- панель квадрата — свиток, полки — бамбуковые дощечки, модальные окна — листы бумаги на столе.

## Типографика и тёмная тема 墨夜

**Единый шрифтовой набор** (Google Fonts; Inter и системные гротески убраны — по правилу
«anti-slop» из [herzigma/frontend-design-prompt](https://github.com/herzigma/frontend-design-prompt)
они перечислены среди запрещённых):

| Токен | Шрифт | Где работает |
|---|---|---|
| `--font-cn` | **Noto Serif SC** (宋体) | все 汉字: имена 卦, печати 印章, триграммы, 燕尾 черты |
| `--font-text` | **Bitter** (слэб-сериф) | стихи, полки, длинные тексты, всё тело сайта |
| `--font-display` | **Prata** (дисплейная антиква) | имена гексаграмм, заголовки окон |
| `--font-ui` | **JetBrains Mono** (моно) | микро-подписи капслоком, кнопки, поиск, цифры, метрики |

Шкала кеглей — через переменные: `--fs-display` (имена, clamp 30–46px), `--fs-title`,
`--fs-poem` (стихи, clamp 19–25px), `--fs-body` 16px, `--fs-label` 10.5px, `--fs-micro` 9.5px.
Правило: **крупное — крупно, служебное — мелко и капслоком** (экстремальный контраст кеглей
из того же промта).

## Шапка-компас: небо и подвижный фарфор

Верхний блок — 9 ячеек (8 триграмм по периметру + «писать тушью» в центре):

- **небо**: размывка селадоном (青瓷 · #5f8f80), азуритом (#3f6d8c) и киноварью по бумаге
  плюс тонкая сетка линий — по правилу «фон никогда не бывает пустым»;
- **подвижный фарфор**: диск глазури (радиальный + конический градиент, `blur(20px)`),
  медленно плывущий по небу — 26 с, одна большая анимация вместо множества мелких;
- **ячейки-плитки**: глазурь, свет изнутри, мягкая тень; появление со стаггером (`cellIn`, задержки 0→0.48 с)
  и очень медленное «дыхание» (`cellFloat`, 11–18 с, отрицательные задержки для рассинхрона);
- кнопка **«прислушаться к ветрам»** — 15px моно капслоком, с рамкой и blur-подложкой;
  центральная **«писать тушью»** — 17px, киноварная печать;
- при `prefers-reduced-motion` все анимации шапки отключаются.

## Морской 3D-фон

**Шрифты** (Google Fonts, с системными запасными):

| Стек | Шрифт | Где работает |
|---|---|---|
| `--font-ru` | **Lora** | стихи, названия полок, длинные тексты |
| `--font-display` | **Playfair Display** | имена гексаграмм, заголовки, названия квадратов |
| `--font-ui` | **Inter** | микро-подписи капслоком, кнопки, метки, поиск |
| `--font-cn` | **KaiTi / Songti** | 汉字: имена 卦, печати 印章, полки |

Правило вёрстки: **крупный serif там, где читают** (стих — 18 px, интерлиньяж 1.95, лёгкий трекинг),
**мелкий гротеск капслоком там, где ориентируются** (подписи 10–11 px, трекинг 0.14em — как строка
`WATER AND SMOKE · SEPTEMBER IN AUGUST`). Смешанные строки («№56 旅 Люй») набираются стеком
`KaiTi → Lora → Inter`: 汉字 уходят в каллиграфию, латиница и кириллица — в свою гарнитуру.

**Переключатель 墨夜** в шапке включает тёмную тему: чёрная бумага `#131317`, кремовая тушь `#f2ead9`,
киноварь и пигменты триграмм остаются. Тема держится на инвертируемых токенах `--ink-rgb` и `--card-rgb`,
поэтому весь CSS работает в обоих режимах без дублирования; выбор запоминается в `localStorage`.

## Морской 3D-фон

`sea.js` рисует на `<canvas id="sea">` псевдо-3D море: 15 линий-волн в перспективе (к горизонту сходятся
и бледнеют, к берегу расходятся и толстеют), двойная синусоида даёт зыбь. Цвета — 石青 (азурит) в глубине
и 青碧 (селадон) у берега, поверх бумажного фона; маска растворяет фон сверху и снизу, поэтому море
не спорит с плитками. Анимация останавливается при `prefers-reduced-motion` и на галочке «без левитации»,
а также когда вкладка скрыта.

## Просмотр вживую

```
node server.js          → http://localhost:8080/
```

Открыть без сервера тоже можно (двойной клик по `index.html`), но через сервер надёжнее: `localStorage` работает всегда,
а файлы отдаются без кеша. Остановить сервер — `Ctrl+C` в том терминале, либо
`Get-Process node | Stop-Process`.

## Автопроверки

```
node scripts/validate.js    данные 64 гексаграмм (структура + канонические коды черт)
node scripts/smoke.js       прогон интерфейса без браузера: свод, панель, расщепление, публикация
```

`smoke.js` поднимает минимальную заглушку DOM и прогоняет 15 проверок: 64 плитки, раскрытие квадрата,
подсказка квадрата по образам, роли строк, редкие слова, конкуренция концептов, попадание текста на полку,
метка на плитке, перерисовка панели.

## Проверка данных

```
node scripts/validate.js
```

Скрипт проверяет: ровно 64 гексаграммы, уникальные id, по 6 подписей полок, корректные триграммы
и канонические шестичертёжные коды (например №63 = 101010, №64 = 010101).
